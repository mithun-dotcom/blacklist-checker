ArrowInBox

Blacklist Checker

Check whether your domain or IP is listed on any major email blacklist.

Runs live IP-based DNSBL and domain/URI blacklist lookups from this server's own resolver, so lists like SURBL, URIBL and Spamhaus return accurate results (unlike browser-only checkers, which those lists refuse). Nothing you enter is stored. DNSBL zone list based on the open-source molodsom/rbl-check project.
